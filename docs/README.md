# Documentation

Written for a reader who wants to understand how [*InSites*](../README.md) works. The specification itself is in [`../system/`](../system/README.md), and the research records are in [`../studies/`](../studies/README.md).

Read in this order.

| | Document | What it covers |
|---|---|---|
| 1 | **[`architecture.md`](architecture.md)** | **The central document.** The seven stages and what the expert decides at each, how the sequence is kept, the marking gate, expert review, the value and context vocabularies, and the version history |
| 2 | [`epistemic-notation.md`](epistemic-notation.md) | The three marks: what each means, where in the stages each acts, how the prose around a mark must read, and what the marks looked like in a study session |
| 3 | [`extensions.md`](extensions.md) | Knowledge Graph, Alternative Reading, Collection Analysis and Image Analysis, and the dashboards |
| 4 | [`Session-Report-spec.md`](Session-Report-spec.md) | The session report, and the six action tags that record who changed what |
| 5 | [`plugin-architecture.md`](plugin-architecture.md) | How the editions for the different platforms are built from one source |
| 6 | [`cbsa-archaeology-layer.md`](cbsa-archaeology-layer.md) | An optional layer for archaeological material, loaded only when it is needed |
