# InSites for ChatGPT Desktop

Early development version, not yet for use in formal assessments. Use
non-confidential trial material.

1. Download [insites-chatgpt.zip](https://github.com/InSites-Lab/insites/raw/refs/heads/dev/downloads/insites-chatgpt.zip).
2. Open **ChatGPT Desktop** in your **Personal** account. Find **Plugin Creator**
   under Plugins and install it if needed. Start a Work conversation with
   `@Plugin Creator` and attach the ZIP.
3. Send:

   > Import this completed InSites ZIP as a private plugin in my account.
   > Preserve all eight skills, their reference files and the included remote
   > MCP connection. Return the installation link.

4. Open the returned link, select **Install plugin**, and complete any connection
   approval ChatGPT requests.
5. Start a **new Work conversation**, select `@InSites`, upload or paste a short
   text of your choice, and write **"Begin assessment."** Answer its questions
   and review the output before continuing.

When approved findings are available, you can ask for a **knowledge graph** or
**dashboard** and use **Ask in chat** to ask about what it shows.

If installation fails, send the error text to the person who shared the package.
