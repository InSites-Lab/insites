# InSites — standalone stage specification (Claude plugin edition)

The active stage is the one the session is in; a stage number 0–6 in the request overrides it. Read the source stage from `references/stage-N.md`, the full epistemic-marking rules from `references/notation.md`, and, when the stage relies on them, the vocabularies in `references/vocabularies.md`. For a Hebrew request, read `references/hebrew-overlay.md`.
