# InSites for DeepSeek · v11.4

[Download the current specification](V-11.4/InSites-deepseek-v11.4.md). This is the only file to load. InSites helps you assess a heritage site from your sources, one stage at a time. You review and approve the work. English and Chinese are supported; visual controls are in English.

## 中文使用指南

1. **准备对话。** 每个遗产地新建一个对话，上传或粘贴上面的完整规范文件，然后发送：
   > 请按这份 InSites 规范工作，用中文回答。确认后等待我上传遗产地资料，不要开始评估。
2. **提供资料。** 上传文献、照片或图纸，保留文件名、页码和来源。输入 **开始评估**，核对第0阶段的资料清单与缺口；确认图片是否可读取。记录日期和界面显示的模型／模式名称，开始时关闭联网搜索。
3. **逐步审阅。** 用 **继续** 进入下一阶段；用 **展开** 深入分析，或直接提出更正。修改后仍应等待你的确认。可以说 **返回第2阶段**。
4. **解读与展示。** 输入 **解读评估**，选择证据分析、利益相关者视角或其他解读；已有评估也可直接上传解读。需要时请求 **知识图谱** 或 **仪表板**，点击 **Run HTML**。时间线在仪表板内。扩展结束后，在对话中选择下一步；图内 **AI Query** 的问题需复制回对话。
5. **保存。** 输入 **保存进度**，保存进度摘要、完整的已确认输出及资料清单。换对话时重新加载规范、这些记录和所需资料。

**如何阅读：** 无标记＝资料明确记载；〰️＝由证据推断；💭＝解读，可商榷。核对引用并提出异议；人工确认不等于事实已被证明。本课程只在评估与解读文字中显示这些标记，知识图谱不显示。

灰色区域是模型的思考草稿，只需阅读下方的回答。若显示失败，将错误原文发回对话，请求保留已确认内容并修正完整 HTML；`Invalid JSON` 不能靠更换浏览器解决。

## English quick start

1. **Prepare a chat.** Start a new chat for each site. Upload or paste the complete specification above, then send:
   > Follow this InSites specification and work in English. Confirm, then wait for my site sources before starting the assessment.
2. **Supply evidence.** Upload documents, photographs or drawings with filenames, page numbers and sources. Say **Start**. Review the Stage 0 source inventory and gaps, including whether images are readable. Record the date and displayed model/mode; start with web search off.
3. **Review each stage.** Say **continue**, **expand**, **go back to Stage 2**, or give a correction. The assistant should wait for your approval after each stage and revision.
4. **Read and visualize.** Say **read assessment** and choose an evidence reading, stakeholder lens or another perspective. You can also upload an existing assessment to read. Request **kg** or **dashboard** when needed and use **Run HTML**. The timeline is inside the dashboard. Choose the next action in chat; copy questions from the graph's **AI Query** back into the conversation.
5. **Save.** Say **save progress**. Keep the capsule, full approved outputs and source inventory. Reload these, the specification and needed sources when resuming in a new chat.

**Reading the text:** no mark = stated in sources; 〰️ = inference from evidence; 💭 = interpretation open to challenge. Check citations and challenge the analysis: approval does not prove a claim. This course keeps these marks in assessment/readings, not the KG.

Read the answer below the grey thinking block. If a display fails, paste the exact error into chat and request corrected complete HTML with unchanged approved findings. Switching browsers cannot repair `Invalid JSON`.
